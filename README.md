# 소년과 함께하는 새 떼 비행

Python과 pico2d로 구성된 기존 소년 예제에 **10마리 새의 좌우 왕복 비행**을 추가한 프로그램이다. 기존 소년의 이동·수면·공 발사, 잔디와 거리 눈금은 같은 화면에서 유지된다.

## 설치와 실행

개발 환경은 Windows, Python 3.13.15, pico2d 1.5.1, transitions 0.9.3이다. 이미지와 글꼴을 상대 경로로 읽으므로 다음 명령은 프로젝트 루트에서 실행한다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

실행 시 1600×600 창에 기존 소년과 배경, 자동으로 비행하는 새 10마리가 표시되도록 구성했다. 새의 실행 의존성은 pico2d이며 기존 소년 상태 머신을 위해 transitions도 필요하다.

## 조작

| 입력·상태 | 기존 소년 동작 |
| --- | --- |
| `←`, `→` | 좌우 달리기 |
| 이동 키 해제 | 대기 상태로 전환 |
| 대기 중 약 5초 경과 | 수면 상태로 전환 |
| 대기·달리기 중 `Space` | 바라보는 방향으로 공 발사 |
| 수면 중 `Space` | 잠에서 깨어남 |
| 수면 중 이동 키 | 달리기 시작 |
| `Esc` 또는 창 닫기 | 프로그램 종료 |

새는 키 입력 없이 날갯짓과 좌우 왕복을 반복한다. 소년 입력은 기존 `Boy.handle_event()`에 전달하며 `boy.py`와 `ball.py`의 동작 코드는 수정하지 않았다.

## 새 애니메이션 구현 논리

### 1. 원본 픽셀을 보존하는 프레임 분할

- `bird_animation.png`는 918×506 RGBA 이미지다.
- 실제 가로 간격은 182픽셀이므로 이미지 너비를 단순히 5로 나누지 않는다.
- 182×170 논리 셀의 5열·3행에서 위쪽 왼편부터 14개 동작만 사용한다. 마지막 칸과 오른쪽 8픽셀은 투명 영역이다.
- 마지막 행은 원본 끝에서 높이가 166픽셀로 끝난다. 이를 170픽셀로 늘리지 않고 같은 배율로 그리며, 빠진 아래쪽 4픽셀에 해당하는 중심 좌표를 보정한다.
- 배율은 `100 / 182`, 논리 표시 높이는 `100 × 170 / 182`이다. 실제 클립 높이를 `h`라 하면 표시 높이는 `h × 배율`, 중심 y 보정은 `(논리 표시 높이 - 실제 표시 높이) / 2`이다.

클립 좌표는 pico2d의 이미지 아래쪽 기준으로 변환한다.

```text
column = index % 5
row = index // 5
left = column × 182
bottom = max(0, 506 - (row + 1) × 170)
height = min(170, 506 - row × 170)
```

예를 들어 0번은 `(0, 336, 182, 170)`, 5번은 `(0, 166, 182, 170)`, 10번은 `(0, 0, 182, 166)`, 13번은 `(546, 0, 182, 166)`이다.

### 2. 렌더링 횟수와 독립적인 날갯짓

```text
frame = (frame + 10 × dt) % 14
그릴 프레임 = int(frame)
```

`dt`는 초 단위 `game_framework.frame_time`이다. 실수 위상에 누적하고 그릴 때만 정수로 바꿔 작은 시간 간격의 진행량을 보존한다. 14개 동작의 한 주기는 1.4초다. 개체별 시작 위상은 `index % 14`이며 경계에서 방향을 바꿔도 초기화하지 않는다.

### 3. 초과 이동 거리를 보존하는 좌우 반사

기본 속도는 180픽셀/초, 표시 너비는 100픽셀이다. 중심 좌표의 이동 범위를 `L = 50`, `R = 1550`으로 잡고 `D = R - L = 1500`이라 한다.

```text
오른쪽 시작 위상 = x - L
왼쪽 시작 위상 = 2 × D - (x - L)

phase = (phase + speed × dt) % (2 × D)
x = L + D - abs(phase - D)
direction = +1 if phase < D else -1
```

이 삼각파는 한 번의 갱신에 여러 경계를 지나도 이동 거리를 보존한다. 정확히 오른쪽 경계에서는 왼쪽으로, 왼쪽 경계에서는 오른쪽으로 향한다. 원본이 오른쪽을 바라보므로 왼쪽 이동에만 `clip_composite_draw()`의 `'h'` 반전을 적용한다. 프레임 순서와 회전각은 바꾸지 않는다.

### 4. 기존 장면과 자원 공유

- 새는 가로 5열·세로 2행으로 배치한다. 초기 위치는 `x = 160 + 320 × 열`, `y = 300 + 180 × 행`이다.
- 짝수 인덱스는 오른쪽, 홀수 인덱스는 왼쪽으로 출발한다.
- 모든 새는 `Bird.image` 하나를 공유한다. 갱신 중 이미지 로딩이나 객체 재생성을 하지 않는다.
- 소년·공과 동일한 월드 갱신·렌더링 루프를 사용한다. 잔디와 거리 눈금은 배경 레이어에 남긴다.
- 중복 `finish()`를 하나로 통합해 소년 참조·새 목록·월드를 정리하고 캔버스 종료 전에 새 이미지 참조를 해제한다.
- 프레임 시간은 단조 고해상도 시계 `time.perf_counter()`로 측정한다. 사용하지 않던 `1 / frame_time` 계산을 제거해 경과 시간이 0인 경우에도 역수를 계산하지 않는다.

## 조정 가능한 값

| 위치 | 상수 | 기본값 |
| --- | --- | --- |
| `play_mode.py` | `BIRD_COUNT` | 10 |
| `bird.py` | `ANIMATION_FPS` | 10.0프레임/초 |
| `bird.py` | `FLIGHT_SPEED_PPS` | 180.0픽셀/초 |
| `bird.py` | `DRAW_WIDTH` | 100픽셀 |

제출 요구사항을 유지하려면 새 개수 10과 원본 프레임 메타데이터는 유지한다.

## 개발 상태와 실행 확인 범위

- 새 프레임 추출, 시간 기반 날갯짓, 좌우 반사와 방향 반전, 소년과의 장면 통합을 구현했다.
- 사용자 추가 요청에 따라 소년 조작·수면·공 발사와 기존 잔디·눈금·격자를 유지했다.
- 테스트 중단 요청 전에는 원본 픽셀 분석, 새의 시간·경계 계산 점검과 새 단독 장면의 캔버스 실행을 수행했다.
- **요청 이후에는 테스트와 실행 확인을 수행하지 않았다. 소년과 새가 함께 나오는 최종 버전의 런타임 결과는 확인하지 않은 상태다.**
- 커밋 수는 기존 문서·초기 이력을 포함해 총 10개로 관리하며, 마지막 커밋 본문에 상세 개발 논리를 기록한다.
